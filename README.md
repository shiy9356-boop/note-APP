# 智能笔记 - AI驱动的现代化笔记应用

一款基于Electron + React构建的现代化笔记应用，集成了强大的AI写作助手功能。

## ✨ 功能特色

### 📝 基础功能
- **富文本编辑** - 集成Monaco编辑器，支持Markdown语法高亮
- **文件夹管理** - 自由创建和组织文件夹
- **实时搜索** - 快速查找笔记内容
- **自动保存** - 无需担心数据丢失
- **快捷键支持** - 提升操作效率

### 🤖 AI功能
- **AI续写** - 智能续写内容，保持风格一致
- **语法纠错** - 修正语法错误和拼写错误
- **内容优化** - 优化表达，使内容更清晰
- **快捷键操作** - ⌘I 续写，⌘E 纠错，⌘O 优化

### 🎨 界面设计
- **现代科技风** - 深色主题，霓虹配色
- **响应式布局** - 适配不同屏幕尺寸
- **流畅动画** - 平滑的过渡效果

## 🚀 快速开始

### 安装依赖
```bash
cd note-app
npm install
```

### 开发模式
```bash
npm run dev
```
这将同时启动React开发服务器和Electron应用。

### 构建应用
```bash
npm run build
```

## 📖 使用说明

1. **创建笔记**
   - 点击顶部"新建"按钮
   - 在标题栏输入笔记标题
   - 在编辑区域开始写作

2. **管理文件夹**
   - 在左侧面板创建新文件夹
   - 点击文件夹切换视图
   - 文件夹右上角显示笔记数量

3. **使用AI助手**
   - 选中需要优化的文本
   - 按下 ⌘I 进行AI续写
   - 按下 ⌘E 进行语法纠错
   - 按下 ⌘O 优化表达

4. **快捷键**
   - ⌘/Ctrl + S: 保存笔记
   - ⌘/Ctrl + N: 新建笔记
   - ⌘/Ctrl + I: AI续写
   - ⌘/Ctrl + E: 语法纠错
   - ⌘/Ctrl + O: 内容优化

## 🔧 技术栈

- **桌面框架**: Electron
- **前端框架**: React 18 + TypeScript
- **编辑器**: Monaco Editor
- **状态管理**: Zustand
- **样式**: Tailwind CSS
- **AI服务**: OpenAI API (集成示例)

## 📁 项目结构

```
note-app/
├── electron/          # Electron主进程
│   ├── main.ts       # 主进程入口
│   └── preload.ts    # 预加载脚本
├── src/
│   ├── components/    # React组件
│   ├── services/     # 服务层
│   ├── store/        # 状态管理
│   ├── types/        # TypeScript类型
│   └── utils/        # 工具函数
└── public/           # 静态资源
```
